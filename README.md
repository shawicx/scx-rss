# SCX RSS Reader

一个基于 Tauri v2 + Vue 3 的本地优先 RSS 阅读器。

## 特性

- 🚀 本地优先，数据完全存储在本地
- 📦 支持 OPML 导入/导出
- 🎨 现代化的 UI 设计
- ⚡ 快速轻量

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm tauri dev

# 构建生产版本
pnpm tauri build
```

## 技术栈

- **框架**: Tauri v2 + Vue 3
- **语言**: TypeScript + Rust
- **样式**: UnoCSS
- **数据库**: SQLite
